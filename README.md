# Task Tracker

Небольшое веб-приложение для управления задачами, разработанное в рамках выполнения лабораторной работы.

Проект предназначен для практического изучения backend-разработки на Python, создания REST API, взаимодействия с базой данных PostgreSQL и интеграции клиентской и серверной частей приложения.

### Технологии

- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic
- **Frontend:** React
- **Database:** PostgreSQL

### Возможности

- Создание и просмотр задач
- Редактирование и удаление задач
- Изменение статуса выполнения
- Управление категориями задач

Проект носит учебный характер.
